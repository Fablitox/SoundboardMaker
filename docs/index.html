EN QUELQUES MOTS

Questions fréquentes.

L’essentiel avant l’installation.

Lire toute la FAQ ↗
Un Stream Deck est-il obligatoire ? +
Non. Le Soundboard intégré fonctionne directement depuis l’application Windows. Le plugin est facultatif et sert à piloter les sons avec les touches d’un Stream Deck.
Wave Link est-il nécessaire ? +
Uniquement pour router les sons vers un microphone virtuel (Discord, chat vocal en jeu) avec la configuration prise en charge. La lecture locale fonctionne sans Wave Link.
Est-ce que le logiciel est disponible en anglais ? +
Oui. Soundboard Maker propose une interface française et anglaise. Le site possède également une page anglaise distincte.
Où installer le plugin Stream Deck ? +
Téléchargez le fichier .streamDeckPlugin depuis GitHub Releases puis ouvrez-le avec Elgato Stream Deck. L’installation manuelle reste nécessaire jusqu’à sa publication sur le Marketplace.
